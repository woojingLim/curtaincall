# 커튼콜 이후 — 올림픽공원 공연 종료 혼잡 운영 의사결정 시뮬레이터 (최종)

2026년도 공공데이터 활용 경진대회(한국체육산업개발) 출품작의 공개용 소스예요. 만든 팀: **크라우드제로**(류시헌·임우징·석지혜).
과거 공연·주차·지하철 공공데이터를 결합해, 운영자가 공연 종료 뒤 혼잡을 줄일 대안(종료 시각 조정·대체 역 안내)을 미리 비교하도록 돕는 도구예요.
2025년 과거 기록으로 만든 시제품이며 **실시간 혼잡·안전·대기시간 예측 서비스가 아니에요.**

**시제품 바로 열기:** <https://woojinglim.github.io/curtaincall/> (로그인 없이 PC·휴대폰 브라우저에서 열려요)

## 파일

| 경로 | 내용 |
|---|---|
| `index.html` | 시제품 웹앱(지도형, 데이터 내장 단일 HTML). 운영자 모드: 요약·새 일정 미리보기·공연일·역별·주차·시뮬레이터, 운영 검토표 인쇄·PDF / 관객 안내 미리보기: 길찾기(카카오맵 도보 길찾기 연결)·주변·막차. 사용법·현장 순서·주의점은 지도 오른쪽 ? 버튼(도움말) |
| `audit.py` | 웹에 내장된 데이터를 `data/` 원본 CSV와 대조(주차 3,456칸·지하철 7,776+7,776칸)하고 관측 지표를 다시 계산 → `observed_metrics.csv` |
| `audit_model.js` | `index.html`의 계산 모델만 꺼내 검사(인원 보존, 0분·0% 원래 값, 참고 상한, 시각표 방향)하고 요약 수치와 새 일정 미리보기 정확도 출력 |
| `analysis/` | `make_figs_v3.py`(기획서 그림 3~8·결과 CSV), `regress_v3.py`(보정 회귀), `similar_eval.py`(새 일정 미리보기 한 날씩 빼고 시험), `make_flow.py`(데이터 흐름 그림), `make_xlsx_v3.py`(결과 엑셀) |
| `results/` | 공연일별 관측·시나리오·새 일정 검증 결과 CSV, 보정 회귀 결과, `결과_V3_관측·시나리오.xlsx`(요약은 수식으로 계산) |
| `src/` | 웹앱 원본 조각(`model.js` 계산 / `core.js`·`ui.js` 화면 / `app.css`, `shell.html`, `M.json`)과 묶는 스크립트 |
| `data/` | 원본·정리 자료(연계 데이터, 승하차 1~8호선·9호선, 열차운행시각표, 도보 시간, 공통 CSV, 1번 공연기준표·주차분석) |
| `data_code/` | 연계 데이터 오픈API 내려받기·정리 코드 |
| `legacy/` | 수정 전 모델의 결과 엑셀. **제출 수치로 쓰지 마세요** |

참가신청서·개인정보 동의서와 서명본은 이 저장소에 올리지 않아요.

## 실행·검증 (네트워크·API 키 필요 없음)

```

```

## 데이터 정의

- **피크**: 마지막 추정 종료 시각이 속한 시간대 ±2시간(자료가 있는 범위) 안의 최대 1시간. 올림픽공원역 = 5호선 승차 + 9호선 순승차(환승 제외).
- **추정 종료**: 시작 시각 + 공연 유형별 러닝타임 가정(콘서트 150분, 팬미팅·팬콘 120분, 쇼케이스 90분). 실제 종료 기록이 아니에요.
- **비교 기준**: 비공연 월~목 시간대별 평균. 주말·공휴일 효과는 통제하지 못해요. **평일 평균 최고치**는 그중 가장 많은 1시간이며 역 수용능력이 아니에요.
- **주차 순감소**: 연속 두 시각의 주차 차량 수 차이(출차 − 입차). 실제 출차 대수가 아니에요. 결측은 0으로 채우지 않아요.
- **공연 수**: 공연 기준표 293건(151일) 중 종료 시각을 정할 수 없는 페스티벌 단독일 7일을 빼고 144일·286건을 분석해요.
- **종료 시각 조정 시나리오**: 종료 예정 간격 0분인 정확히 두 공연일(23일)에 작은 공연 몫(좌석 비율 가정)의 초과 승차를 늦춰요. 인원은 보존되고, 자정 이후로 넘어가면 감소율을 판정하지 않아요.
- **대체 역 분산 시나리오**: 원래 피크 시간 초과 승차의 일부를 주변 4개 역에 '평일 평균 최고치까지의 여유'에 비례해 나눠요. 넘는 몫은 옮기지 않고(미배분), 이동 뒤 다른 시간대까지 피크를 다시 계산해요.
- 두 시나리오는 독립 계산이라 감소율을 더하면 안 돼요.
- **새 일정 미리보기**: 공연장·시작 시각·유형(·예상 관객 수)을 넣으면 공연장 구성·추정 종료 시간대·종료 간격·요일이 가장 비슷한 2025년 공연일 7일의 피크 중앙값과 최소~최대를 참고 범위로 보여 줘요. 예측 모델이 아니에요.
- **운영 검토표**: 공연일·새 일정마다 관측·시나리오·검토 항목을 A4 한 장으로 인쇄하거나 PDF로 저장해요.
- **관객 안내 미리보기**: 2025년 같은 공연일의 승차 기록·열차운행시각표·카카오맵 도보 시간으로 탈 역과 열차를 보여 줘요. 도보 시간을 재지 않은 공연장은 KSPO DOME 값으로 어림하고 화면에 표시해요. 지도는 약도예요(역·공연장 좌표는 위키백과, 올림픽홀은 도보 거리로 추정).
